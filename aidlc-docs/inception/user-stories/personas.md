# Personas

ターゲットペルソナは「同業エンジニア・デザイナー」1種に絞る。
ページの設計・コンテンツ・受け入れ基準はすべてこのペルソナ視点で評価する。

---

## Persona 1: 同業エンジニア・デザイナー

| 属性 | 内容 |
|------|------|
| **名称** | Dev Peer / デブピア |
| **役割** | エンジニア（フロント/バック/インフラ問わず）またはデザイナー |
| **経験年数** | 3〜10年程度（中堅クラス） |
| **デバイス** | 業務時間中はPCブラウザ、移動中・カンファレンス中はスマホで閲覧することが多い |
| **訪問動機** | 技術的な交流相手の発見、コラボの可能性検討、勉強会・OSSコントリビュータ探し、リクルーティング相手の確認、純粋な技術的興味 |
| **重視する情報** | 使える技術スタック、過去のアウトプット（OSS/ブログ/登壇）、得意分野、連絡手段（GitHub/LinkedIn 等の技術系プロフィール） |
| **ニーズ** | 短時間で「この人と話す価値があるか」を判断したい |
| **嫌うこと** | 情報過多、装飾過多、レスポンシブが崩れているページ、連絡手段が分かりにくいページ |
| **デザイン感度** | 高い。配色やタイポグラフィに敏感で、テーマ切り替え機能のような遊び心も評価する |
| **言語** | 日本語または英語（海外エンジニアとの接点もある） |

### このペルソナがページに期待する体験
1. PCで開いたら、必要十分な情報（プロフィール・スキル・ポートフォリオ・ブログリンク）が一覧でき、3秒で「何の人か」が分かる
2. スマホで開いたら、即座に「デジタル名刺」のように連絡先・スキルが見えて、必要なら GitHub/LinkedIn にすぐ飛べる
3. テーマカラーを切り替えて、ページのデザインセンスや実装力を肌で感じられる
4. 必要に応じて英語表示に切り替えられる
